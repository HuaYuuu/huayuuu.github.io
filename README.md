# Yi Li Academic Homepage

This is a static personal academic website for Yi Li, focused on computer vision, adverse-weather image restoration, multimodal image fusion, and visual perception.

The site includes:

- Profile summary
- Research interests
- Recent updates
- Filterable publications
- Projects and systems
- Education and experience
- Honors, service, and applied research outputs
- Download links for the academic CV and job resume

Open `index.html` directly in a browser to preview the site. Most structured content lives in `script.js`, while the main page layout is in `index.html`.
